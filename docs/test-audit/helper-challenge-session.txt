HELPER RECOMMENDATION CHALLENGE — SESSION REVIEWER — 2026-11-03

Scope
Independently reviewed 11 requested helper files/rows against their actual consumer tests and production boundaries. The current shell_support_helpers.csv already marks ManualUiTimerScheduler and TestCoordinatorSubstitutes KEEP, so those are confirmations of the revised result, not invented REWRITE disputes. No CSV, production or test files edited; static read-only review, no test execution. Root and audit_shell_support receive this report for reconciliation.

Principle
A fixture need only supply the collaborator behavior a surviving test actually needs. It need not emulate all production persistence, cancellation, event timing or revision behavior. Safe unrelated defaults reduce boilerplate. Reject a test when its asserted rule is supplied entirely by a fake; do not solve that by making the fake a more complete copy of production. A constructor graph's size or one test class using a separate helper file is not by itself a reason to split or duplicate it.

Use await using at actual ownership sites before TempDatabase removes files.
