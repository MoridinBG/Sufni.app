Support and infrastructure audit
Assigned support-only file: Sufni.App.Tests/Setups/Views/Editors/SetupEditorViewTestContext.cs (118 lines). Reviewed in full; no invented test rows. It is a reasonable narrowly scoped fixture shared by compact/workspace tests and already centralizes resource/template setup, real editor creation and cleanup. Keep that shape, expose board input explicitly instead of unconditional Guid.NewGuid if board-specific view scenarios are required, and use common mounting helpers for host close/dispatcher drain. Do not promote this into a giant feature-agnostic harness.
